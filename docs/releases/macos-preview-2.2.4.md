# W.O.F NAI Studio · macOS 2.2.4 试用版

这是 Miint-Sunny fork 的 macOS 预发布包，用于试用后再向 [W.O.F 上游](https://github.com/z15087716457-stack/W.O.F_NAI_Launcher)提交适配。它与本仓库原有 Aaalice 发布分开，不替代原来的 Latest。

基于 W.O.F 2.2.4 及其后续 multipart 精准参考 / 错误说明修复，包含 Mac 适配、省电和按请求统计 Anlas、生成失败与重试改进。测量脚本与集成测量夹具不包含在发布源码中。

## 下载与安装

下载 `WOF_NAI_Studio_macOS_2.2.4-macos-preview_Portable.zip`；旁边的 `.sha256` 用于校验。需要 macOS 12 或更高版本，ZIP 包含 Apple 芯片和 Intel 架构；Intel 尚待实机验证。

用访达解压，将 `W.O.F NAI Studio.app` 拖入“应用程序”。这是标准 W.O.F 应用身份 `com.wof.naiStudio`，数据在该身份的“应用支持”目录。它不是此前私有的 `W.O.F NAI Studio 试用.app`，不要直接把它当作同一数据身份覆盖；两者可以分别保留。

应用采用 **ad-hoc 临时签名，没有 Apple 公证**。macOS 15 及以上首次打开被拦截时，先尝试打开，再到“系统设置 → 隐私与安全性”选择“仍要打开”。其他系统按 README 的首次打开步骤操作。

源码版本为 `2.2.4-macos-preview+76`。Apple 版本字段会去掉预发布后缀，应用内可能显示 `2.2.4`、构建号 `76`；本页标签、构建链接与源码提交用于准确区分试用包。

## 这几天重点试用

- 从访达启动后的登录、正常生成、保存、图库浏览、⌘ 快捷键、关闭窗口 / 菜单栏与重新打开。
- Agent 技能、提示词、本地 MCP 与包管理；取消连接检查后是否正确结束后台进程。
- 放着不操作、最小化和隐藏后的 CPU；空闲微动默认关，也可手动选择防烧屏或原本效果。
- 网络异常、429 等待、账号 / 参数错误、批量停止与重试；随机 / 顺序块被拒后提示跳过次数且不提供无效重试。

余额只在启动、登录 / 换号、点击和必要的低余额 / 低 Opus 额度检查时刷新。Anlas 统计按成功请求的应用报价记录，可能与服务端账单不同；缓存额度尚未更新、或服务端已处理但结果返回前取消 / 断线时尤其如此。

## 已知范围

RAG 仅支持 Apple 芯片；SeedVR2 和 RTX Video 仍仅支持 Windows。资源窗口是主窗口里的浮动面板。历史性能数字见测量报告，本版没有冒称重新做过实机能耗测量。

CI 使用合成接口验证，不调用真实 NovelAI 或模型。真实使用体验以这几天的试用反馈为准；上游 PR 尚未提交。
